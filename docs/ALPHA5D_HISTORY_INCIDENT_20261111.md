## 根因及独立发现

1. **本次阻断的直接原因**：`sessions < 60`才允许新股排除；恰好60日仍须参加全A验收。模型`c[-61:-1]`计算此前60个收盘价的突破，连同当前收盘需要61根。该第61根在11月11日早上尚未产生。修改数据源、清缓存或重跑都不能补出真实历史。
2. **备用源未被触发**：原`daily_history`只对异常切换备源；主源合法但较短的响应立即返回。补丁增加完整备源尝试及逐路根数/首尾日期/URL/hash。两路都只有60根时保持短历史、继续阻断。
3. **备用源解析缺陷**：真实`qfq.js`形如`var sh688828qfq={...}\n/* ... */`，通用`json.loads`因尾部注释报Extra data。补丁按确切证券变量解码JSON，只允许分号/注释尾部；校验因子行数、日期唯一性和有限正值，不执行JS，也不默认复权因子为1。此问题是当前真实响应复现的恢复能力缺陷；原早盘没有尝试备源，不能把它倒推为早盘直接根因。
4. **缓存隐患与本次因果区分**：原逐股缓存只检查最后日期，未核验完整字段、身份或长度。补丁拒绝短、损坏、错证券、错日期/复权、重复、未来或盘中缓存并重新请求。原运行attempt=2恢复`alpha5d-history-v1-42846793887`后又用同键保存，确实出现无法占用已存在键的警告；这是可复现的重试保存问题。归档与重新请求相符、原5027次日线均实际请求成功，未发现该键冲突导致这两份60根数据缺日。
5. **调查时主分支已有变更**：`c018fad`在09:19加入`technical_warmup_60_bars`，允许排除恰好60日证券。这不是本次失败时的代码，也不在PR #7中。本补丁依据“不得放宽门槛”的要求撤回该新增评分资格例外，保留两股和全轮失败，改为明确的`INSUFFICIENT_OBSERVED_SESSIONS`诊断。
6. **已有回归暴露的审计缺口**：基线主分支的`FrozenPreviousClose.test_missing_actual_page_still_fails_closed`已失败，确认是近期冻结分页改动遗失successful_pages校验。本补丁恢复成功页、缺页和原始行数的严格核验，没有把测试改成接受缺页。
